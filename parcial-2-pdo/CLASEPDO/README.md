Se hizo un sistema de gestion de productos(Agregar, Actualizar, Eliminar) ademas la opcion de buscar, aplicando la arquitectura MVC para separar la logica de la interfaz. Se uso Namespaces para organizar las clases por carpetas y un Autoload para cargar los archivos automaticamente sin usar require. La conexion a la base de datos se hizo con PDO y sentencias preparadas para evitar inyeccion SQL. Para el diseño se aplico Bootstrap.
